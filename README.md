# CryptoSticky

Промо-лендинг маркетплейса коллекционных криптостикеров с аукционами в реальном времени, рейтингом продаж и каталогом стикерпаков.

[Демонстрация сайта](https://lelyaler.github.io/crypto-sticky/)

## Разделы и функциональность

- Главный экран с актуальным дропом недели и быстрыми действиями
- Бегущая строка котировок популярных коллекций
- Блок live-аукциона с таймером обратного отсчёта и модальным окном для совершения ставки
- Сетка других аукционов и каталог всех активных лотов
- Слайдер новинок на базе Swiper с кастомной нумерацией
- Форма подписки на рассылку новинок
- Форма подачи заявки для авторов с прикреплением файлов
- Таблица лидеров «Топ продаж» с котировками в ETH / USD
- Интерактивный FAQ в виде аккордеона
- Модальное окно подключения Web3-кошелька

## Стек

- HTML5
- CSS3 (Flexbox, Grid, адаптивная вёрстка)
- Vanilla JavaScript (ES6+)
- Swiper.js

## Запуск проекта

Открыть файл `index.html` в браузере или запустить через локальный сервер:

```bash
# Python
python3 -m http.server 8000

# Node.js
npx serve
```
